Đúng, mình hiểu ý bạn. Hiện tại cần **sửa flow authentication/navigation trước**, rồi mới dựng **Base Layout dùng chung cho toàn bộ app, trừ POS**.

Source UI/UX hiện tại cũng đã định hướng template hierarchy:

`base layout → authenticated layout → POS layout / admin layout`, và Login thành công phải đi vào **Application Shell**, không phải POS trực tiếp. fileciteturn1file0L118-L145 fileciteturn1file7L1427-L1440

### Flow nên chốt

```text id="khoeln"
                    ┌──────────────┐
                    │    LOGIN     │
                    └──────┬───────┘
                           │ success
                           ▼
                 ┌────────────────────┐
                 │ APPLICATION / HOME │
                 │     BASE SHELL     │
                 └─────────┬──────────┘
                           │
          ┌────────────────┼────────────────┐
          ▼                ▼                ▼
      Products          Orders          Customers
          │                │                │
          ▼                ▼                ▼
       Stock             Debts           Reports
                                           
                           │
                           ▼
                    ┌─────────────┐
                    │     POS     │
                    │ POS Layout  │
                    └─────────────┘

LOGOUT
   ↓
invalidate/revoke session
   ↓
redirect LOGIN
```

Đặc biệt **POS không nên là trang mặc định sau login**. POS là một workspace riêng; Base Shell là nơi chứa các màn hình application/admin thông thường.

Và logout phải kết thúc bằng redirect về Login, thay vì quay lại một trang trung gian.

Mình sẽ coi đây là **Phase 2.14 — Authentication Flow + Global Base Layout**, chứ không nhét vào POS nữa. UI source list cũng đang định hướng Phase 2.14 cho Login UI/UX + Global application UI/UX. fileciteturn1file6L1254-L1260
