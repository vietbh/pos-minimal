==================================================

Thiết kế theo nguyên tắc:

> WRITE PATH bảo vệ business correctness.
>
> READ PATH tối ưu cho tốc độ và UI.
>
> Repository bảo vệ persistence boundary.
>

>
> Entity chỉ được load khi thực sự cần business behavior.

Và đặc biệt:

> **Không tối ưu bằng cách làm architecture phức tạp.**

> **Ưu tiên MySQL + Doctrine + index đúng + projection + pagination + tránh N+1.**
